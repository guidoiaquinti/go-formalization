Go orders pairs by Addr.Compare first and unsigned uint16 port only when the addresses compare equal. Addr.Compare orders by family bit length, then the two unsigned address limbs, then lexicographic zone for equal IPv6 words. Mapped IPv6 has IPv6 width. The Lean theorem captures each of the three comparison outcomes with this modeled ordering. The sampled comparison uses empty and decimal zones, and the model uses Lean strings for zones.
