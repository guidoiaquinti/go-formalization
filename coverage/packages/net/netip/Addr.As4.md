Go 1.27.0 tests the native IPv4 detail handle first, then the IPv6 detail class and exact mapped prefix. On success, the big-endian store of the low word truncated to 32 bits gives the final four address bytes. The Lean theorem states this branch condition, its byte digits, and both exact recovered string panic payloads. The zero address and other IPv6 receivers take distinct panic branches. Scoped IPv6 keeps the same class and words for this decision. [Pinned source](https://github.com/golang/go/blob/go1.27.0/src/net/netip/netip.go#L712-L724)

The registered comparison checks Go and Lean against the input bytes and an explicit prefix test, including all 96 one-bit changes to the mapped prefix. It passed 100 boundary cases and 60,000 samples on darwin/arm64 with seeds 17, 2718, and 65537. Run `go run ./difftest/net/netip/addr-as4/check.go` from the repository root after building the registered Lean driver.
