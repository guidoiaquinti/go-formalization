Go 1.27.0 bytes/bytes.go treats signed rune values at or below 127 as
separators except the ASCII alphanumeric ranges and underscore. For larger
runes it excludes letters and digits and then checks Unicode space. The
Lean wrapper reuses the reviewed string classifier with the same source
structure. Above ASCII that classifier uses the pinned white-space range
table. The author comparison independently checks that Go's White_Space
table has no overlap with either letter or digit categories, justifying
that simplification, then checks every code point through U+10FFFF,
including surrogates, directly against the private bytes helper. It also
checks 12 outside-range boundaries and 60,000 signed rune words with
seeds 17, 2718 and 65537. The proofs cover the ASCII guard (including
negatives), all negative runes and the upper bound of Unicode whitespace.

On darwin/arm64 the independent control exercised private Go by same-package
overlay and the Lean executable over 174 fixed runes. Fixtures include all
128 ASCII values, every non-ASCII space and adjacent runes, negative and
high positive int32 inputs, and Unicode category counterexamples. The
underscore-as-separator, ASCII-only and unsigned mutants disagree on 1,
19 and 2 fixtures respectively.
