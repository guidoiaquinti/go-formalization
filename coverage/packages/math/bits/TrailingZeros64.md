The arm64 compiler listing shows RBIT and CLZ in the default driver and the de Bruijn table reference with intrinsics disabled. The Lean model preserves wrapping negation and multiplication. Its kernel proof isolates the first set bit and checks the decoder for every possible one-bit input. For an arbitrary nonzero word the theorem identifies the least set bit and proves that all lower bits are clear. Zero returns 64.

The arm64 default profile permits compiler intrinsics, and the disabled profile exercises the source implementation.
