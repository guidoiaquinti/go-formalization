I checked the pinned Go 1.27.0 branch in `src/math/gamma.go` and its use of `Modf`. The strict comparison rejects both signed zeros and all NaNs. Negative infinity passes the sign comparison and produces a NaN fractional part, so it also returns false. For a strictly negative finite input the zero-fraction check corresponds to retaining all bits under truncation. The subtraction is exact because the truncated integer is zero or its magnitude is within a factor of two of the original magnitude. The Lean theorem expresses the equivalent sign, finite exponent, and zero fractional residue for every binary64 input.

I ran `go run difftest/math/is-neg-int/check.go` on Go 1.27.0, darwin/arm64. The in-package overlay passes raw words to the private helper. Go and Lean matched the exact rational oracle on 518 boundaries and 20,000 cases per seed 17, 2718, and 65537.

I ran `go run difftest/math/is-neg-int/review/main.go`. The overlay control passed 11 fixed cases. Testing the sign bit instead of strict negativity falsely accepts negative zero. Skipping the integrality check falsely accepts three finite negative fractions, including -1.5.
