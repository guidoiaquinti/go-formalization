The generic source computes the negative of `Floor` applied to the negative of the input. The Lean model follows that composition by flipping the sign bit at both boundaries and using the generic Floor formula. On finite inputs negation reverses the ordering, so the greatest integer below the negated input maps to the least integer above the original one. Both sign flips preserve the sign of an input zero, and a negative input strictly between negative one and zero yields negative zero. [Pinned Ceil source](https://github.com/golang/go/blob/go1.27.0/src/math/floor.go#L36-L52) · [Lean model](../../../lean/GoLean/Math/FloorCeil.lean)

An exact rational quotient and remainder independently checks the result. Go 1.27.0 and Lean agreed on 94 boundaries and 60,000 samples per profile on darwin/arm64, with seeds 17, 2718 and 65537. The runs call public `math.Ceil` normally and with compiler intrinsics disabled in the driver and math package. On this platform the wrapper can still select assembly. Each run also checks the private `ceil` function via an overlay with normal build settings. The private function calls the public `Floor` wrapper internally. Native NaN results are compared by class. [Differential comparison](../../../difftest/math/floor-ceil/check.go) · [ARM64 assembly](https://github.com/golang/go/blob/go1.27.0/src/math/floor_arm64.s)
