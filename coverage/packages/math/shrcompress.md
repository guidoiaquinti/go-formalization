I checked Go 1.27.0's `shrcompress`, `shr`, and `nonzero` in `src/math/fma.go`. Count zero returns the original words. Count 64 copies the high word into the low word and includes the nonzero indicator for the discarded low word. Counts at least 128 return only the indicator of whether either input is nonzero. For counts strictly between 0 and 64, the discarded bits are the masked low word. For counts strictly between 64 and 128, they include the entire low word and the masked portion of the high word. The Lean model preserves those branches and the bitwise OR with the indicator. Its theorem equates the returned word pair to the joined unsigned shift with the least-significant bit additionally set if the input remainder modulo (2^n) is nonzero.

Go and Lean agreed on 421 boundary cases and 20,000 generated cases per seed 17, 2718, and 65537. The boundaries include isolated bits on both sides of the discarded region, count 64, count 128, and maximum native uint.
