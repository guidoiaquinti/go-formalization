The pinned byte-slice validator consumes one ASCII byte and then tries blocks of one, two, and repeatedly four native words, using strict length guards and a high-bit mask. The model expresses the packed mask as per-byte ASCII checks and reuses the UTF-8 width classifier for non-ASCII bytes. Its theorems cover all-ASCII acceptance, empty input, and the malformed and valid multibyte head steps. Correspondence of the complete validator with the pinned table and packed execution is checked on the differential domain. [Pinned source](https://github.com/golang/go/blob/go1.27.0/src/unicode/utf8/utf8.go#L460-L519)
