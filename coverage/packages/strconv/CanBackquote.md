Go decodes each rune and rejects a width-one decoding error, BOM, backquote, DEL, and ASCII controls other than tab. Correctly encoded U+FFFD has width three and is accepted. Other valid multibyte runes, including U+0085, pass this test. Lean decodes the entire input before checking the same character restrictions. The theorem characterizes the result with respect to Lean's decoder. Cross-decoder equivalence is tested on the stated domain.
