The empty branch returns a nil Color without calling the query. The nonempty branch calls `Index` and then reads the selected interface from the palette. Go can observe a different slot value from the callback that supplied its score. The Lean model represents each callback outcome and the post-selection value separately. Its theorems establish the empty result, selected value at a valid slot, and propagation of the callback trace and panic. The selected-slot theorem assumes the returned index is in range. For a nonempty palette, Go initializes the index to zero and can replace it only with a range-loop index. The proof abstracts callback effects outside the recorded trace, outcomes and post-selection slot value. [Pinned Go source](https://github.com/golang/go/blob/go1.27.0/src/image/color/color.go#L279-L308) · [Lean model](../../../../lean/GoLean/Image/Color/PaletteConvert.lean)

The Go comparison checks nil and nonnil empty palettes, returned interface identities, ordered callback traces, replacement of a visited slot, and outcomes for panic and nil interfaces. Its oracle selects a slot by an independent per-channel distance calculation for premultiplied colors. Go 1.27.0 and Lean agreed on 14 boundaries and 60,000 samples on darwin/arm64. Each of seeds 17, 2718 and 65537 supplied 20,000 cases. [Differential comparison](../../../../difftest/image/color/palette-convert/check.go)
