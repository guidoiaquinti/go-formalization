The pinned helper returns an existing YCbCr value directly. For another Color it calls RGBA once, discards alpha, shifts the RGB words right by eight, and passes the truncated bytes to RGBToYCbCr. The Lean cases preserve that branch order and prove that extraction equals division by 256 followed by truncation to a byte. The model records panic and call count. The Go fixture checks callback panic identity as well as the runtime panic on a nil Color. [Pinned source](https://github.com/golang/go/blob/go1.27.0/src/image/color/ycbcr.go#L228-L238) · [Lean model](../../../../lean/GoLean/Image/Color/YCbCrModel.lean)

The differential invokes the actual private helper using a same-package test overlay. [Go comparison](../../../../difftest/image/color/ycbcr-model/check.go)
