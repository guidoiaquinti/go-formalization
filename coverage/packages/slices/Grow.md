The pinned source rejects negative counts with the string "cannot be negative". It subtracts spare capacity from the requested count and reuses the original view when the result is nonpositive. Otherwise it appends zero cells to the old full-capacity view, which copies visible and hidden cells into new storage, and restores the original length. The Lean theorems characterize the panic, reuse and extension. The model covers successful allocations with nonzero-size elements and representable lengths. Exact allocator rounding and oversize panics are outside the claim. [Pinned Go source](https://github.com/golang/go/blob/go1.27.0/src/slices/slices.go#L417-L430) · [Lean model](../../../lean/GoLean/Slices/Grow.lean)

The Go comparison checks copied hidden cells, zeros through the requested capacity, original and guard storage, and base pointer identity. It also checks the panic payload and the observed nilness. [Differential comparison](../../../difftest/slices/grow/check.go)
