Go returns false for an empty visible range or a zero-size element type. Otherwise it compares each first byte address against the other slice’s last byte address, including the last element’s remaining bytes. Lean proves that these inclusive inequalities are equivalent to sharing a byte in the two half-open visible ranges. The theorem uses mathematical addresses. Its source correspondence assumes valid contiguous slices and representable last-byte pointer arithmetic. [Pinned source](https://github.com/golang/go/blob/go1.27.0/src/slices/slices.go#L454-L467) · [Lean model](../../../lean/GoLean/Slices/Overlaps.lean)

Go 1.27.0 and Lean agreed on 16,200 exhaustive eight-slot cases and 60,000 samples in 64-slot regions on darwin/arm64, using seeds 17, 2718 and 65537. The cases cover shared and separate arrays and element sizes zero, one, three and eight. The comparison calls the private helper through a test-only bridge and uses a scan of common element indices in shared storage. Equal element sizes and element-aligned slice starts make common indices equivalent to a shared byte in these fixtures. [Differential comparison](../../../difftest/slices/overlaps/check.go)

Go passed all six independent three-byte fixtures and the nonempty zero-size fixture. Extending the viewed ranges to capacity failed three cases. Including the byte immediately beyond either range failed both adjacent-range cases.
