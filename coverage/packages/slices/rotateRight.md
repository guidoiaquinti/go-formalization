Go computes the left rotation count as `len(s) - r` using signed native-width arithmetic and hands that count to `rotateLeft`. Lean models the wrapped subtraction with a bit vector. For an in-range right count the adjusted count is representable and the proof gives the right-rotated visible sequence with spare cells unchanged. The two other theorems give the original backing state when the adjusted count fails the first slice bounds check, and the prefix reversal when it fits capacity but exceeds length.
