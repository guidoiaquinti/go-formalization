The method delegates to the corresponding search wrapper. The Lean theorem proves that the method model returns the partition index, or the slice length if no element qualifies. The predicate is the binary64 ordered comparison, so a NaN element never qualifies and a NaN key gives the slice length. An ascending numeric suffix preceded by NaNs partitions the predicate. Signed zeros compare equal. The proof assumes the partition and the Go comparison exercises the cross-runtime float semantics.
