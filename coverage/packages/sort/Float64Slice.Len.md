Go returns the visible slice length without reading any element. The Lean theorem proves that taking a valid list view returns the difference between its upper and lower bounds. The list stores arbitrary binary64 words. Nil and nonnil empty slices have the same length, while capacity and backing storage are outside the claim. The Go driver creates actual two-index subslices of backing lengths from 0 through 256, using positive infinity and words with NaN payloads as elements.
