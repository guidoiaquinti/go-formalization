The wrapper searches for the first element at least as large as the key. The Lean model instantiates the binary-search interval with the signed comparison and proves it returns the partition boundary. Ascending order ensures that all indices before that boundary fail the predicate and all following indices satisfy it. The Go unsigned midpoint recovers the exact nonnegative sum of two valid native int indices before halving, since that sum fits in uint. The samples include duplicate-rich slices, native-width values and keys drawn from the slice. Go passed all six independent fixtures. Replacing the inclusive predicate with strict greater-than failed three cases, including the duplicate-key lower bound.
