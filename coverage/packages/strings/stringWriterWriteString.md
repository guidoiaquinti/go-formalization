The pinned adapter converts the raw string to a byte slice, calls its embedded writer's `Write` once, and returns the count and error unchanged. The Lean theorems cover the single payload and unchanged reply, including signed counts. The native comparison checks that an empty string produces a nonnil empty argument and that a dual-interface writer receives `Write`. Writer panics and side effects beyond payload and reply are outside scope.
