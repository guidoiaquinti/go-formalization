The pinned method returns the byte slice length. The Lean model returns the length of the stored bytes for either buffer state, independently of reserved capacity, and models the nil receiver panic. [Pinned source](https://github.com/golang/go/blob/go1.27.0/src/strings/builder.go#L50-L51) · [Lean model](../../../lean/GoLean/Strings/BuilderLen.lean)

Go 1.27.0 and Lean agreed on 262 boundary cases and 60,000 samples with seeds 17, 2718 and 65537 on darwin/arm64. The comparison includes every singleton byte, and scripts that grow, write and reset the builder. [Go comparison](../../../difftest/strings/builder-len/check.go)

The independent control checks an empty builder, reservation, writes of multibyte and malformed input, reset, and the nil receiver. Go passed all six checks. After the writes, both capacity and decoded rune count differed from the accumulated byte length. Run `go run coverage/packages/strings/controls/BuilderLen/main.go`.
