I checked Go 1.27.0's dispatch in `src/strings/strings.go`. ASCII delegates to byte search. A RuneError key uses the native range loop, which emits U+FFFD for a valid U+FFFD sequence and for malformed input. Invalid keys are rejected before converting a key to UTF-8. For other valid keys, the source filters by the encoding's last byte, then confirms the preceding bytes. The model expresses that branch as a first exact encoding match. The theorems cover the first match, invalid-key rejection, and the RuneError range step. UTF-8 primitive correspondence and optimized candidate selection are checked by the differential.
