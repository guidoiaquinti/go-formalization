Go starts each invocation at byte zero, records the start of each field, and yields the original byte substring at whitespace or end of input. The scan uses the ASCII table before decoding non-ASCII bytes and testing Unicode whitespace. The Lean model captures these operations and proves that a bounded callback run yields the corresponding prefix of an unrestricted run. Exact field boundaries and restarting the iterator are exercised by comparison. Backing storage and callback effects beyond stopping are outside scope.
