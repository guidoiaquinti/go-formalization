The pinned function rejects negative offsets before accessing the receiver. For a nonnegative offset it checks the backing length, then copies up to the destination length and returns EOF for a short copy. The Lean theorems cover both error branches and the exact copied prefix and unchanged suffix. The Go driver also observes the unchanged receiver fields.
